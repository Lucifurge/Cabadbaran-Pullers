# Cabadbaran Pullers Registration

1. Create a Google Sheet.
2. Rename Sheet1 to Registrations.
3. Open Extensions > Apps Script.
4. Paste Code.gs contents.
5. Deploy as Web App:
   - Execute as Me
   - Anyone can access
6. Copy Web App URL.
7. Paste URL into script.js WEB_APP_URL.
8. Upload logo.png (included) beside index.html.
